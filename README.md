# ScreenWrite

Professional collaborative screenwriting for desktop. Write in proper screenplay format, break down scripts for production, draw lined-script coverage, and generate shot lists and per-actor sides, all in a fast native app that runs locally on your machine.

> This repository hosts the public releases and the auto-update manifest for ScreenWrite. The application source is closed.

## Download

ScreenWrite runs on Windows and macOS.

- **Buy and download:** <https://creativedivergence.gumroad.com/l/screenwrite>
- Builds are published under [Releases](../../releases).

## Updates

ScreenWrite keeps itself current. When a new version is published, the app downloads and applies the update automatically, with no manual reinstall needed.
